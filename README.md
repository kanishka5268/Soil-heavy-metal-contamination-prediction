# Soil Heavy Metal Contamination Prediction

## Overview
This project compares various Machine Learning models to predict soil heavy metal contamination.

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- Gradient Boosting
- SVM

## Dataset
Source: https://www.kaggle.com/datasets/ziya07/soil-heavy-metal

## Results
Logistic Regression achieved the highest accuracy of 97.5%

## How to Run
1. Clone the repository
2. Install requirements
3. Open the notebook
