# Soil Heavy Metal Contamination Prediction

## Overview

This project performs a comparative analysis of multiple Machine Learning models for predicting soil heavy metal contamination. It includes data preprocessing, exploratory data analysis (EDA), PCA, feature importance analysis, SHAP explainability, and hyperparameter tuning to identify the best-performing model.

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- Gradient Boosting
- SVM

## Dataset
Source: https://www.kaggle.com/datasets/ziya07/soil-heavy-metal

## Results
XGBoost achieved the highest accuracy of 97.5%
